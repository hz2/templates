# latex-template

A modular LaTeX paper template with an Ipe diagram pipeline.

Two entry points share the same `preamble/`:

- `main.tex` -- a paper: title, abstract, table of contents, content split
  across `sections/*.tex`, bibliography.
- `notes.tex` -- running notes: title, table of contents, bibliography, but
  content is written directly inline as you go (no abstract, no splitting
  into section files) -- for the "keep adding to this doc over a course/
  project" case rather than a finished paper.

## CI

`.github/workflows/build.yml` builds both `main.tex` and `notes.tex` (via
`nix develop`) on every push/PR and uploads the resulting PDFs as workflow
artifacts -- a quick way to catch a broken build without compiling locally.

## Setup

```
nix develop
```

gives you `pdflatex`, `biber`, `latexmk`, `ipe`, `ipetoipe`, `iperender`, and
`pdftoppm` in `$PATH`.

## Building

```
make build       # export figures, then compile main.tex -> build/main.pdf
make notes       # export figures, then compile notes.tex -> build/notes.pdf
make watch       # latexmk -pvc main.tex, rebuilds on save
make watch-notes # latexmk -pvc notes.tex, rebuilds on save
make figures     # (re)export figures/ipe/*.ipe -> figures/pdf, figures/png
make clean
```

## Layout

```
main.tex              thin entry point: preamble + sections + bibliography
preamble/              modular preamble, split by concern
  preamble.tex          aggregator, \input'd by main.tex
  packages.tex           \usepackage list
  colors.tex              palette shared with figures/style.isy
  layout.tex               geometry / headers / hyperref
  theorems.tex              tcolorbox theorem environments
  macros.tex                 generic macros (\ceil, \floor, \code, \fig, ...)
  math-macros.tex            optional domain notation pack, opt in per-paper
sections/              one file per section, \input'd from main.tex
references.bib         biblatex bibliography
figures/
  ipe/                  diagram sources, edit these (plain XML)
  style.isy              shared Ipe palette (matches preamble/colors.tex)
  pdf/, png/              generated by `make figures`, not committed
scripts/export-figures.sh
```

## Adding a section

Add `sections/NN-name.tex` and `\input{sections/NN-name}` it from `main.tex`.

## Adding a diagram

Diagrams are authored as plain XML in `figures/ipe/*.ipe` and referenced from
LaTeX with `\fig{width-fraction}{name}{caption}` (see `preamble/macros.tex`).
See `figures/ipe/example.ipe` for a worked example, and the `ipe-diagrams`
Claude Code skill for the create/render/review workflow.

Theorem-box colors and diagram colors share one palette: six named colors
defined in both `preamble/colors.tex` (LaTeX) and `figures/style.isy` /
embedded in each `.ipe` file (Ipe) -- `lightblue`, `lightgreen`,
`lightorange`, `lightred`, `lightpurple`, `lightteal`.
